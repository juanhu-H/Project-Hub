# Reflexión sobre un LLM/SLM local

## Rol

Un modelo local podría redactar respuestas, resumir documentos y proponer relaciones candidatas. No reemplazaría las reglas de trazabilidad ni la validación humana.

## Aporte

- privacidad;
- continuidad sin API externa;
- costo marginal menor;
- experimentación interna.

## Información nueva para el equipo

- consumo de memoria y CPU/GPU;
- latencia real;
- calidad de respuestas en español;
- tasa de error en términos técnicos;
- complejidad operativa.

## Limitaciones frente a una API en la nube

- menor capacidad de razonamiento en modelos pequeños;
- hardware;
- actualización y seguridad;
- observabilidad;
- escalabilidad;
- mantenimiento.

## Prueba opcional

Instalar Ollama y ejecutar un modelo pequeño para responder sobre un fragmento documental. La salida debe presentarse como demostración, no como componente obligatorio del MVP.
