# Tecnologías y justificación

| Tecnología | Uso | Justificación |
|---|---|---|
| React | Frontend | Componentes reutilizables y SPA sencilla |
| Vite | Build frontend | Configuración rápida y build estático |
| FastAPI | Backend | API tipada, documentación OpenAPI automática |
| SQLite | Persistencia MVP | Cero infraestructura para la demo |
| PostgreSQL | Evolución productiva | Multiusuario y despliegue administrado |
| Neo4j | Grafo opcional | Relaciones navegables y consultas de impacto |
| Python | Agentes | Ecosistema de IA, APIs y procesamiento |
| JWT + Argon2 | Seguridad | Sesiones firmadas y contraseñas protegidas |
| Jira REST API | Integración | Información estructurada y auditable |
| Docker | Ejecución | Entorno reproducible |
