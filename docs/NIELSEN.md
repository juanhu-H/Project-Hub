# Autoevaluación UX/UI según Nielsen

1. **Visibilidad del estado:** mensajes de carga, último ciclo y estados.
2. **Correspondencia con el mundo real:** Jira, endpoints, pruebas y reportes usan terminología del equipo.
3. **Control del usuario:** aprobación/rechazo de relaciones.
4. **Consistencia:** mismos estilos y prioridades.
5. **Prevención de errores:** no se aprueban automáticamente relaciones semánticas.
6. **Reconocer antes que recordar:** evidencias y enlaces visibles.
7. **Flexibilidad:** buscador y datos demo.
8. **Diseño minimalista:** dashboard con pocos módulos.
9. **Recuperación ante errores:** mensajes explícitos de backend.
10. **Ayuda:** README y documentación OpenAPI.
